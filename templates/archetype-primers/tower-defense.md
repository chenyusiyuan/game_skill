# Tower Defense 品类 Primer

> 适用于“塔防”“固定路线防守”“放塔打怪”“波次守基地”的 query。
> 核心是路线、波次、经济、塔差异和漏怪惩罚。

## 别名

- 中文：塔防 / 路线防守 / 放置防守 / 守基地 / 防御塔。
- 英文：tower defense / TD / fixed-path defense / wave defense.
- 代表作：Kingdom Rush / Bloons TD / GemCraft / Desktop Tower Defense / Plants vs. Zombies。
- 关键识别词：路径、波次、塔、升级、金币、基地生命、怪物漏过。
- 近邻但不同：RTS 强调单位调度；lane defense 强调多车道；survivors 强调玩家走位。

## 品类公约

- 敌人沿可见路线前进，路线必须一眼能读懂。
- 玩家在允许区域放塔，塔自动攻击进入范围的敌人。
- 经济循环是击杀得钱，再放塔或升级。
- 塔至少有两种差异：单体高伤、范围低伤、减速、连射或穿透。
- 波次要有准备期和进攻期，下一波前给玩家短暂决策时间。
- 漏怪扣基地生命，不是立刻失败。
- 塔范围要可视化，放置前预览比放置后发现无效更友好。
- 敌人至少有普通、快速、厚血或护甲一种变化。
- 升级必须改变外观或弹道，不只是数字变强。
- HUD 显示金币、基地生命、波次、下一波按钮或倒计时。

## 经典反馈瞬间

| 瞬间 | 可执行反馈 |
|---|---|
| 放置塔 | 范围圈收缩，塔基座落地，金币数字扣减跳动 |
| 金币不足 | 预览塔变红，按钮抖动，短文字提示 |
| 塔开火 | 炮口闪光，弹体飞向目标，命中点小爆炸 |
| 敌人死亡 | 敌人碎裂，金币飞向 HUD，路线上清出空间 |
| 升级塔 | 塔体变高或加部件，范围圈扩张，等级徽标出现 |
| 开始波次 | 路径入口警告闪烁，波次标题滑入 |
| 漏怪 | 基地红闪，生命扣除，漏怪在终点淡出 |
| boss 入场 | 更大影子和血条，路径上出现重脚步震动 |

## 常见 mistake

1. 路径不清楚，玩家不知道怪从哪里来去哪里。
2. 放塔区域和路径重叠，碰撞或寻路变混乱。
3. 塔没有范围预览，玩家无法做决策。
4. 所有塔只是不同颜色，攻击差异不可见。
5. 经济太紧，玩家第一波后无事可做。
6. 怪物血太厚，击中很多次却没反馈。
7. 波次之间没有准备时间，玩家不能规划。
8. 升级只改伤害，外观和弹道不变。
9. 漏怪立即失败，学习成本过高。
10. 弹体太快或不可见，看不出塔在工作。

## 数值起点

- 地图建议：640x480；路径宽度 48-72 px，塔格 40-56 px。
- 初始金币：80-140；基础塔价格 35-60；高级塔价格 70-110。
- 击杀奖励：普通怪 5-8，快速怪 6-10，厚血怪 12-20。
- 基地生命：10-20；boss 漏过可扣 3-5。
- 基础塔范围：90-140 px；狙击塔 180-240 px；减速塔 80-120 px。
- 攻速：快塔 0.2-0.4 秒；普通塔 0.6-0.9 秒；炮塔 1.1-1.8 秒。
- 普通怪 HP：20-45；快速怪 HP 12-25；厚血怪 HP 90-180。
- 怪物速度：普通 45-70 px/s；快速 90-130 px/s；boss 30-45 px/s。
- 波次规模：第 1 波 8-12 只；每波 +20-35% 总生命量。
- 准备期：5-10 秒；first-cut 可用按钮手动开波。
- 升级成本：塔价的 70-120%；升级后伤害或攻速提升 30-60%。
- first-cut 目标：3 波、2-3 种塔、2 种敌人、明确漏怪扣血。

## 不要照搬

- 不要照搬 Kingdom Rush、Bloons 或 PVZ 的角色、美术、音效和关卡。
- 如果 query 是 lane defense，可以保留波次和经济，但路线改成多车道。
- 如果 query 是开放造路，不要硬套固定路径，需要单独说明复杂度风险。
- 如果 query 是极简数字塔防，也要保留范围、弹体、金币变化三类反馈。
- 如果 query 是儿童向，降低漏怪惩罚，提高放置预览和奖励反馈。
- 如果首交付时间紧，优先做路径、放塔、自动攻击、波次、经济。
- 任何偏离品类公约的选择，都要在 decisions 里说明理由。
