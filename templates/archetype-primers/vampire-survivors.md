# Vampire Survivors 品类 Primer

> 适用于“割草”“类幸存者”“自动攻击生存”“被怪潮包围并升级”的 query。
> primer 是品类知识，不是固定模板；读后把适用和丢弃的点写进 decisions。

## 别名

- 中文：吸血鬼幸存者 / 幸存者 like / 割草 / 肉鸽生存 / 自动战斗生存。
- 英文：survivors-like / reverse bullet hell / auto-attack survival / arena survival.
- 代表作：Vampire Survivors / Brotato / 20 Minutes Till Dawn / Holocure / Soulstone Survivors。
- 关键识别词：自动攻击、怪潮、经验宝石、升级三选一、活过 N 分钟。
- 近邻但不同：双摇杆射击强调瞄准；动作 roguelike 强调手动技能；塔防强调固定路线。

## 品类公约

- 玩家主要操作是走位，不是频繁瞄准或点按攻击。
- 攻击多为自动触发，玩家通过位置控制命中效率和生存空间。
- 怪物从屏幕边缘持续涌入，密度随时间增长。
- 经验宝石或金币掉在地上，拾取半径和吸附反馈很重要。
- 升级通常短暂停表，给 3 个选择，选完回到战斗。
- 武器成长要能看见：数量、半径、冷却、穿透或持续时间至少变一项。
- 一局有强时间感：30 秒、60 秒、5 分钟节点都应出现新压力。
- 敌人不能只换颜色；至少区分快速小怪、厚血怪、远程或精英。
- 屏幕拥挤是乐趣来源，但玩家附近要留出可读空间。
- 后期目标是“我变强了”，不是单纯“怪更多了”。

## 经典反馈瞬间

| 瞬间 | 可执行反馈 |
|---|---|
| 击杀小怪 | 6-10 个碎片粒子，尸体淡出，经验宝石弹出到地面 |
| 宝石拾取 | 宝石先停顿 80ms，再弧线吸向玩家，经验条跳动 |
| 升级触发 | 画面短暂停住，金色环扩散，三选一卡片弹入 |
| 选择升级 | 卡片闪光，武器图标亮起，下一次攻击立刻体现变化 |
| 被包围 | 玩家周围红色危险圈，生命条抖动，最近敌人轻微击退 |
| 精英入场 | 边缘警告箭头，精英带轮廓描边，掉落更大的奖励 |
| 磁吸道具 | 全屏宝石同时转向玩家，形成明显的收束流线 |
| 时间节点 | 计时器闪烁，下一波怪物颜色或体型有可见变化 |

## 常见 mistake

1. 把玩家做成手动瞄准射击，导致品类核心变成 shooter。
2. 怪物数量太少，玩家没有被包围和开路的压力。
3. 怪物直接生成在玩家脸上，造成不可避免受伤。
4. 宝石没有吸附半径，玩家必须精准踩点，节奏变碎。
5. 升级只改内部数值，画面上看不出武器变强。
6. 敌人全部同速同血，后期只是更多圆点。
7. 没有计时节点，玩家不知道自己撑过了什么。
8. 生命反馈只扣数字，没有红闪、击退或无敌窗口。
9. 场景太暗或怪物太花，玩家和经验宝石不可读。
10. 所有奖励都立即到账，缺少“吸过来”的爽感。

## 数值起点

- 画布建议：640x480 或 800x600，玩家居中活动半径充足。
- 玩家速度：150-220 px/s；冲刺类角色可到 260 px/s。
- 基础自动攻击冷却：0.6-1.2 秒；范围脉冲可 1.5-2.5 秒。
- 基础攻击伤害：10；小怪 HP 10-25，厚血怪 HP 60-120。
- 小怪速度：35-75 px/s；快速怪 90-130 px/s。
- 初始生成：每 1.2 秒 2-4 只；60 秒后可到每 0.5 秒 5-8 只。
- 经验宝石价值：小怪 1，精英 8-20；升级需求从 6 开始，每级乘 1.25。
- 拾取半径：默认 36-56 px；磁吸道具临时提升到 240-480 px。
- 受伤无敌：0.8-1.2 秒；击退距离 20-45 px。
- 升级选项：每次 3 个，至少 1 个直接增强当前武器。
- 精英间隔：45-75 秒；掉落宝箱或大经验。
- 局内目标：first-cut 可做 90-180 秒生存，不必直接做 30 分钟。

## 不要照搬

- 不要照搬 Vampire Survivors 的角色、武器名、图标或音乐意象。
- 如果 query 强调“魔法阵防守”，可以保留自动攻击和升级，但弱化移动速度。
- 如果 query 强调“弹幕躲避”，敌弹可增多，但仍要保持自动输出的核心。
- 如果 query 是儿童向或休闲向，怪潮密度降低，奖励反馈保留。
- 如果 query 是黑白极简风，宝石也要有形状差异，不能只靠颜色。
- 如果首交付时间紧，优先做走位、自动攻击、经验、升级四件事。
- 任何偏离品类公约的选择，都要在 decisions 里说明理由。
