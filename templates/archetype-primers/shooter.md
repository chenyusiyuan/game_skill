# Shooter 品类 Primer

> 适用于“飞机大战”“雷霆战机”“弹幕”“战机射击”“双摇杆射击”的 query。
> primer 提供品类公约和数值起点，不要求所有 shooter 都同一种节奏。

## 别名

- 中文：飞机大战 / 雷霆战机 / 弹幕 / 战机射击 / 飞行射击 / 清版射击。
- 英文：shooter / shoot 'em up / shmup / vertical scrolling / bullet hell / twin-stick shooter.
- 代表作：雷霆战机 / 1942 / Raiden / Touhou / Ikaruga / Galaga / Geometry Wars。
- 关键识别词：战机、敌机、子弹、闪避、boss、火力升级、清屏。
- 近邻但不同：幸存者类强调自动攻击和升级；塔防强调放置与路线；topdown 强调探索或房间战斗。

## 品类公约

- 玩家专注移动、闪避和火力路线；开火可自动或半自动。
- 玩家弹和敌弹必须颜色、形状或亮度明显区分。
- 玩家命中体积应小于显示体积，常用 50-70%。
- 敌人按波次出现，至少有直线、斜线、弧线或停顿射击的差异。
- powerup 拾取必须带来立即可见变化，如多一条弹道或更大爆炸。
- boss 需要入场提示、血条和阶段反馈。
- 背景可以滚动，但不能让弹幕读不清。
- 失败反馈要给短无敌，避免连续受伤。
- 分数、连击、火力等级至少一个形成持续目标。
- 弹幕密度提升要配合敌弹速度，不要又快又密。

## 经典反馈瞬间

| 瞬间 | 可执行反馈 |
|---|---|
| 击毁普通敌机 | 8-12 粒子爆炸，分数飘起，敌机残影快速淡出 |
| 击毁精英敌机 | 18-28 粒子，短白闪，掉落 powerup 或大分数 |
| boss 入场 | 顶部警告条，背景减速，boss 血条从中间展开 |
| boss 阶段变化 | 血条分段碎裂，弹道变色，屏幕短震 |
| 玩家受击 | 战机闪烁 1 秒，红色边框闪，生命图标减少 |
| 拾取 powerup | 道具吸附到战机，火力轨迹立刻增加或变宽 |
| 清屏炸弹 | 中心白环扩散，敌弹消失，敌机按距离延迟爆炸 |
| 连击中断 | 连击文本下坠变灰，音高回落 |

## 常见 mistake

1. 玩家弹和敌弹同色，玩家无法判断该躲什么。
2. 命中体积等于贴图体积，边缘擦弹体验很差。
3. 敌机只从顶部直线下落，30 秒后单调。
4. powerup 只加分，不改变火力外观。
5. boss 没血条，玩家不知道战斗是否有效。
6. 背景星点太亮，和子弹争夺注意力。
7. 死亡后立即结束，没有生命数和无敌恢复。
8. 难度只靠敌人更多，弹幕空间被填死。
9. 敌弹速度过快，玩家看见时已经来不及躲。
10. 分数没有飘字或连击，击毁反馈不够“脆”。

## 数值起点

- 玩家速度：220-320 px/s；双摇杆地面 shooter 可 180-260 px/s。
- 玩家弹速：420-650 px/s；敌弹 120-260 px/s，弹幕系可更慢更密。
- 普通敌 HP：1-3 发一级弹；精英 HP：8-20 发；boss HP：80-240 发。
- 玩家生命：3；受击无敌 1.0-1.6 秒。
- 普通敌速度：60-130 px/s；俯冲敌可 180 px/s 但数量少。
- 开火冷却：0.12-0.25 秒；散射武器 0.25-0.45 秒。
- powerup 间隔：20-35 秒或每 12-20 个击杀。
- 波次时长：25-45 秒；boss 每 3-5 波或 90-150 秒。
- 爆炸粒子：普通 8-12，精英 18-28，boss 分段 40+。
- 屏幕震动：普通击毁不用；精英 120ms；boss 300-500ms。
- 敌弹安全间距：初期至少 36-52 px，后期可收窄。
- first-cut 目标：90 秒内出现两种敌人、一次 powerup、一个小 boss。

## 不要照搬

- 不要照搬任何真实战机、商标、角色或原作关卡。
- 如果 query 是“慢节奏战略射击”，降低弹速，提高预警和命中反馈。
- 如果 query 是“双摇杆”，把四向移动和鼠标方向作为核心，而不是垂直卷轴。
- 如果 query 是“弹幕躲避”，可以弱化击杀，但必须保留可读弹幕形状。
- 如果 query 是“复古街机”，可以简化色数，但玩家弹和敌弹仍要区分。
- 如果首交付时间紧，优先做移动、射击、敌波、碰撞、powerup。
- 任何偏离品类公约的选择，都要在 decisions 里说明理由。
