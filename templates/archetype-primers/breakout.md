# Breakout 品类 Primer

> 适用于“打砖块”“弹球消砖”“Breakout”“Arkanoid”“挡板反弹”的 query。
> 重点是清晰的球路、挡板控制、砖块消除和失误恢复。

## 别名

- 中文：打砖块 / 弹球消砖 / 挡板反弹 / 砖块破坏。
- 英文：breakout / brick breaker / Arkanoid-like / paddle ball.
- 代表作：Breakout / Arkanoid / DX-Ball / Ricochet / Shatter。
- 关键识别词：挡板、球、砖块、反弹、掉落道具、清关。
- 近邻但不同：pinball 强调复杂桌台；pong 强调对抗；bubble shooter 强调发射匹配。

## 品类公约

- 玩家控制水平挡板，核心输入是左右移动。
- 球与挡板接触点影响反弹角度，不能总是镜面反射。
- 砖块被击中要立刻有破碎或颜色变化。
- 关卡目标通常是清空砖块或击破关键砖块。
- 掉落道具要有正负效果，但 first-cut 可先做正向道具。
- 失误是球落到底部，通常扣生命并重置球。
- 球速随时间或清砖进度轻微上升。
- 顶部和边墙反弹必须稳定，不能穿墙或卡边。
- HUD 显示分数、生命、关卡或剩余砖块。
- 球太快时要有拖尾，否则玩家读不到路径。

## 经典反馈瞬间

| 瞬间 | 可执行反馈 |
|---|---|
| 球击中挡板 | 挡板短闪，球拖尾重置，角度随接触点改变 |
| 普通砖碎裂 | 砖块缩小 100ms，4-8 个碎片，分数飘字 |
| 硬砖受击 | 颜色变浅或裂纹加深，短促撞击震动 |
| 清空一行 | 整行连锁闪光，剩余砖块计数跳动 |
| 掉落道具 | 从砖块位置下落，带图标和颜色区分 |
| 接到道具 | 挡板变宽或球变多，持续时间条出现 |
| 漏球 | 底部红闪，生命减少，球回到挡板上方等待发射 |
| 通关 | 砖块残影向上飞散，下一关标题滑入 |

## 常见 mistake

1. 球速初始太快，玩家还没学会就连续漏球。
2. 反弹角完全镜面，玩家无法主动控球。
3. 砖块没有受击反馈，只是突然消失。
4. 挡板太窄，容错低；太宽又没有挑战。
5. 球和砖块颜色接近，路径不可读。
6. 砖块布局太满，没有通道变化。
7. 道具下落速度太快，玩家来不及判断。
8. 球卡在水平或垂直方向，长时间无进展。
9. 漏球后立刻发射，没有重置喘息。
10. 剩余少数砖块时球路过慢，收尾拖沓。

## 数值起点

- 画布建议：640x480；砖块区高度约 180-240 px。
- 挡板宽度：80-120 px；高度 12-18 px。
- 挡板速度：420-650 px/s；移动有轻微加速度也可。
- 球半径：6-10 px；初始速度 220-320 px/s。
- 最高球速：420-520 px/s，超过后需要明显拖尾。
- 反弹角范围：离中心越远越斜，最大水平夹角约 55-65 度。
- 普通砖 HP：1；硬砖 HP：2-3；特殊砖掉落概率 12-20%。
- 砖块网格：8-12 列，4-7 行；砖间距 4-8 px。
- 生命：3；漏球重置等待 0.8-1.5 秒。
- 分数：普通砖 10，硬砖每击 5，击破 20，连击可 +2 递增。
- 球速增长：每击破 10 个砖块 +3-5%，上限封顶。
- first-cut 目标：一关 40-70 个砖块，60-120 秒可清完。

## 不要照搬

- 不要照搬 Arkanoid 的关卡图案、道具名或素材。
- 如果 query 是儿童向，降低球速，增大挡板，保留破碎反馈。
- 如果 query 是极简风，砖块仍要有 HP 和道具的形状差异。
- 如果 query 是物理玩具风，可以加重力或弧线，但要说明偏离经典规则。
- 如果 query 强调 puzzle，布局和特殊砖优先于高速操作。
- 如果首交付时间紧，优先做挡板控球、砖块破坏、漏球、通关。
- 任何偏离品类公约的选择，都要在 decisions 里说明理由。
